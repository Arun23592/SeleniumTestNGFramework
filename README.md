This project is a robust and scalable Test Automation Framework built using Selenium WebDriver, TestNG, and Java. It is designed to automate web application testing with a focus on reusability, maintainability, and scalability. The framework supports various features like parallel execution, data-driven testing, and integration with reporting tools.
Features
Modular and Reusable Code: The framework is designed with a Page Object Model (POM) to ensure reusability and maintainability.

Parallel Execution: Supports parallel test execution using TestNG to reduce execution time.

Data-Driven Testing: Integrates with Excel, CSV, or JSON to enable data-driven testing.

Cross-Browser Testing: Supports testing across multiple browsers (Chrome, Firefox, Edge, etc.).

Reporting: Generates detailed test reports using ExtentReports or Allure Reports.

Logging: Implements Log4j for logging test execution details.

CI/CD Integration: Can be integrated with CI/CD tools like Jenkins for continuous testing.

Exception Handling: Robust exception handling and screenshot capture for failed tests.

Configuration Management: Uses properties files for managing test configurations (e.g., URLs, browser settings).

Technologies Used
Programming Language: Java

Test Framework: TestNG

Automation Tool: Selenium WebDriver

Build Tool: Maven

Reporting: ExtentReports / Allure Reports

Logging: Log4j

Version Control: Git

CI/CD Integration: Jenkins (optional)
